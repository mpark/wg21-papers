# C++ Committee Papers

This repository contains the source code for various proposals and the
`generated/` directory contains the generated proposals (HTML or PDF).

## Active

- [P2688R6][]: Pattern Matching with `match` and `case`
- [P3549R0][]: Diverging expressions - with Bruno Cardoso Lopes, Zach Laine, and Barry Revzin.
- [P2806R5][]: `do` expressions - with Bruno Cardoso Lopes, Zach Laine, and Barry Revzin.

## Accepted

- [P2169R4][]: A Nice Placeholder With No Name - with Corentin Jabot; accepted for C++26.
- [P0655R1][]: `visit<R>`: Explicit Return Type for `visit` - accepted for C++20.
- [N3887][]: Consistent Metafunction Aliases - accepted for C++14.

## Historical

- [P3527R1][]: Pattern Matching: *variant-like* and `std::expected`.
- [P3521R0][]: Pattern Matching: Customization Point for Open Sum Types.
- [P2688R5][]: Pattern Matching: `match` Expression - did not reach consensus for inclusion in C++26.
- [P3476R0][]: Slides for P2688R2 - Pattern Matching: `match` Expression.
- [P1469R0][]: Disallow `_` Usage in C++20 for Pattern Matching in C++23 - rejected by EWG.
- [P2211R0][]: Exhaustiveness Checking for Pattern Matching - accompanied P1371.
- [P1371R3][]: Pattern Matching - superseded by the P2688 design.
- [P1260R0][]: Pattern Matching - merged with P1308 into P1371.
- [D0080R1][]: Tweaks to the Kona Variant - encouraged to return as P-papers.
- [P0080R0][]: Variant: Discriminated Union with Value Semantics - not presented.
